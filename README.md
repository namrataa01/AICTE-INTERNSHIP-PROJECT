AI-Powered Image Cartoonization Using OpenCV and Python

This project demonstrates how to convert a human image into a cartoon-style representation using traditional image processing techniques. It was developed as part of my AICTE Project.

Features
- Reads and processes images with OpenCV
- Converts color images to cartoon-style illustrations
- Uses edge detection, bilateral filtering, and k-means color quantization
- Visualizes outputs using Matplotlib

Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
